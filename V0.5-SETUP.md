# v0.5 Setup

1. Run `supabase-v0.5-missions.sql` in Supabase SQL Editor.
2. Replace:
   - `index.html`
   - `styles.css`
   - `js/app.js`
3. Keep your existing `config.js` with the real Supabase values and admin PIN.
4. Commit and push.

## New behaviour

### Daily missions
Open Manage secret missions, enter the PIN, then choose Daily missions.
You can edit the theme, photo instruction and video question for all seven days.

### Secret assignments
Choose one assigned subject for each explorer.
The app automatically creates five pairing upload slots, one for the assigned subject with every other family member.

Secret photos are stored separately from the daily gallery.
